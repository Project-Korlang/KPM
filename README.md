# KPM - Korlang Package Manager Registry

Welcome to the official package registry for the **Korlang** programming language.

## Usage

To use this registry with KPM, add the following to your global config:

\`\`\`toml
[registry]
url = "https://project-korlang.github.io/KPM/"
\`\`\`

## Submit a Package

To submit a package, please open a Pull Request adding your package metadata to the \`packages/\` directory.
